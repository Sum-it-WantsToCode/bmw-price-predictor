# bmw-price-predictor
A simple Machine Learning model that predicts the price of the car by checking the attributes of the car such as model, mileage, etc. by using Linear Regression.
This is a lightweight Machine Learning mini-project built to predict the secondary market value of BMW vehicles.
The script processes a dataset of used cars and trains a predictive model based on core depreciation factors.
This project was built to practice data processing, model training, and algorithmic prediction using Python.
Language used is Python and libraries used is Pandas and scikit-learn.
The current error margin is expected due to the simplicity of the features used. Future iterations of this model will focus on feature engineering to reduce the MAE by including:
Specific model series (e.g., 3 Series vs. M5)
Engine type and displacement
Trim levels
